# Creator Program V1

**STATUS: IMPLEMENTED.** Creator es un User con `ProgramEnrollment(CREATOR)` activo, distinto de Affiliate pero con el mismo sistema de enlaces, UTM, attribution, `RewardRule`, ledger y payout. Admin enrola, configura vigencia/código y reglas; el dashboard expone resultados agregados y solicitud de payout.

Creator tiene prioridad sobre Affiliate, pero detrás del Promoter acreditado; una conversión sólo genera una reward. Campaign es un dominio operativo para `membership_purchased`, no una segunda comisión.
