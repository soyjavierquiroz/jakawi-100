# Gate de preparación del piloto Cochabamba

**CURRENT / AUTHORITATIVE.** Único gate GO / NO-GO para el primer piloto comercial real. No reemplaza documentos históricos ni acredita QA nueva. [CURRENT](../CURRENT.md) conserva estado; el [Manual](MANUAL_DE_INVENTARIO.md) define reglas y las [plantillas](templates/README.md) registran ofertas individuales. No fija cantidades: producto/comercial deben justificar suficiencia y valor real.

Estado conocido: **piloto NOT STARTED; bloqueador principal: REAL INVENTORY**. El inventario comercial real sigue requerido. Los demás puntos requieren evidencia; esta documentación no los declara READY.

Copiar esta evaluación a un registro operativo autorizado, con fecha de corte, responsable y referencias de evidencia sin credenciales ni datos personales en Git. Para cada punto elegir READY, BLOCKED o NOT APPLICABLE; hasta verificar, usar BLOCKED (pendiente de evidencia).
