# Affiliate Program V1

**STATUS: IMPLEMENTED.** Affiliate es un User con `ProgramEnrollment(AFFILIATE)` activo. Comparte `/r/{CODE}` y enlaces UTM, ve métricas agregadas y solicita payout de CASH disponible. No ve datos personales de referidos ni altera atribución, Memberships o reglas.

La recompensa se decide con el único beneficiario de adquisición: Promoter, Creator, Affiliate, Member, Partner o ninguno. `RewardPayout` reserva rewards disponibles, requiere mínimo configurable, y Admin paga externamente con referencia o rechaza con motivo. No hay proveedor automático ni datos bancarios recolectados por el programa.
