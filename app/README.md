# Aplicación JAKAWI

Laravel 13 + React 19/TypeScript/Inertia 3. Este directorio procede del Laravel React Starter Kit y conserva su licencia MIT; las instrucciones operativas de JAKAWI están en el repositorio raíz.

Comenzar en el [README del proyecto](../README.md) y el [índice de documentación](../docs/README.md). **No usar ni inspeccionar PHP del host.** Usar Docker PHP 8.4; no ejecutar scripts de setup/migración contra producción como bootstrap de desarrollo.
